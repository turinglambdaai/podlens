五分钟上手

下载、打开、配一次密钥、听一集。教程到这里就结束了——本页其余内容都是可选的。

  1. 安装。到 Releases 下载最新版：macOS 把 DMG 里的应用拖进「应用程序」（Apple Silicon 与 Intel 分架构下载）；Windows 双击 MSI 安装，或解压便携 zip 直接运行。
  2. 首次启动。macOS 未公证构建先右键应用选「打开」。没有账号，不需要注册。首次启动是空库，应用会打开「发现」面板。
  3. 添加一期播客。点左下角 +，粘贴一期播客的 RSS 地址，回车。或者从「发现」面板的精选目录里挑一档，一键添加。
  4. 配置密钥（一次即可）。按 ⌘,（macOS）打开设置，填 api-base 和 api-key（详见下方 BYOK 配置）。转写、翻译、总结都走你自己的大模型 API。
  5. 听并听懂。选一集，点播放。想读懂它：点「一键听懂」，下载、转写、翻译、总结一次完成；逐句稿跟随播放高亮，点句子即跳转。

订阅管理

左栏是订阅列表。点 + 添加，粘贴 RSS 地址；「发现」面板内置 16 档经典英文播客（科技 / 安全 / 科学 / 设计 / 商业 / 资讯），也支持全目录搜索（iTunes Search API，无需密钥）。

  • 自动刷新：每 30 分钟刷新全部订阅，新单集自动出现（macOS 弹系统通知）。
  • 未播标记：单集可标已播 / 未播，侧栏徽章显示每档未播数。
  • 取消订阅：右键订阅项即可，已生成的逐句稿和总结保留在本机。

转写 / 翻译 / 总结

选中一集，点 一键听懂：下载 → 转写 → 翻译 → 总结，一次排队完成。已完成的阶段自动跳过——中断后重跑，只为缺的部分付费。

动手之前先看价：操作区显示字符与句数估算（BYOK 账单是真金白银）。逐句稿支持双语 / 只看译文 / 只看原文三种视图，点句子即跳转播放。

  • 播放：倍速 1.0–3.0×，±15/30 秒快进快退，睡眠定时器，章节跳转（播客含 Podcasting 2.0 章节时）。
  • 连续播放：一集听完自动接同一节目下一集；下次打开从上次的进度继续。
  • 系统媒体键、Control Center（macOS）与任务栏媒体控件（Windows）直接可用。
  • 全部结果缓存在本机：一集只处理一次，结果永远可读、可导出。

BYOK 密钥配置

按 ⌘,（macOS）或从菜单打开设置，逐项填写。key 只存本机 ~/.podlens/config.json，从不上传、从不同步。

配置项 填什么
api-base OpenAI 兼容服务的 API 地址，以 /v1 结尾，例如 https://api.openai.com/v1。DeepSeek、Groq、SiliconFlow、本地 Ollama 均可——具体地址看你的服务商文档。
api-key 服务商控制台里生成的密钥（sk-…）。粘贴进去，点保存。
chat-model 翻译和总结用的对话模型，默认 gpt-4o-mini。按服务商支持的型号名填写。
asr-model 转写模型，默认 whisper-1。要求服务商提供 /audio/transcriptions 端点。
target-lang 翻译目标语言：zh 或 en。修改后需重新翻译已有单集。
先测一集短的。 密钥填好后，挑一集 10 分钟以内的单集跑「一键听懂」，确认三个阶段都通过，再去处理长单集——长单集按句计费，成本随长度增长。

不想用云服务？本地跑 Ollama 时 api-base 填本机地址即可；只需注意转写阶段仍需要支持音频输入的端点。

FAQ

数据存在哪里？

全部在 ~/.podlens/：订阅与单集元数据（library.json）、音频缓存（audio/）、逐句稿、翻译与总结（纯 JSON）。备份这个目录，就备份了一切；删掉它，就卸载了一切。

需要注册账号吗？

不需要。没有账号、没有云端依赖。唯一的密钥是你自己的大模型 API key，存在本机。

支持哪些平台？

macOS 14+（Apple Silicon 与 Intel）和 Windows 10+（x64，MSI 安装器或便携 zip）。Linux 宿主在路线图上，暂无下载。

界面语言和主题怎么换？

设置面板（⌘,）里有中文 / English 切换。深浅色主题跟随系统外观。CLI 输出语言由 ui-lang 配置控制。

怎么卸载？

两步：把应用移到废纸篓（Windows 卸载 MSI 或删掉便携目录），再删除 ~/.podlens/。后者包含你的全部数据——不删它，重装后数据还在。

应用内更新失败了？

去 Releases 页手动下载新版覆盖安装：macOS 重新拖一次 DMG，Windows 重跑 MSI 或替换便携目录。更新走 Ed25519 签名清单校验，失败时不会安装半截的更新。

macOS 提示「无法打开」？

构建目前为 ad-hoc 签名（公证在路线图上）。右键应用 → 「打开」→ 再点「打开」，之后不再提示。
