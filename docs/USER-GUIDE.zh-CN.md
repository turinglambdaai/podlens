# PodLens 使用指南

[English](USER-GUIDE.md) · **简体中文**

收听播客，并可用自己的模型密钥生成逐句转写、翻译和总结。

## 当前可用状态

免费 BYOK 应用。不提供 PodLens 托管 AI 订阅；模型用量由配置的服务商收费。

## 平台与安装

提供 macOS、Windows、Linux 桌面预览；移动与伴随端尚未交付。Linux 当前通过 PODLENS_LANG 选择语言。

从[官方 Releases](https://github.com/turinglambdaai/podlens/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

## 第一次使用

1. 通过发现页搜索或添加播客 RSS，先播放一集，不启动 AI 任务。
2. 分别选择具备音频转写和文本翻译能力的服务商与模型；二者能力可能不同。
3. 先测试短节目并检查用量，再验证逐句稿导出和播放恢复，最后处理大型资料库。

## 数据、备份与恢复

数据默认在 ~/.podlens：config.json、library.json、audio/、transcripts/。退出后再备份。当前 config.json 在本地保存 API key，安全存储迁移待完成。不要放入共享备份；或加密备份，并在泄露后轮换密钥。

## 联网、密钥与隐私

RSS、目录搜索和音频下载会访问相应服务。转写会向选择的服务商上传音频；翻译和总结会发送文字。本地 Ollama 可用不表示它同时支持音频转写。

## 已知限制

取消与恢复、安全存储及三宿主打包证据仍在 #13 跟进。Windows MSI 更新使用新版安装器，不会静默替换安装目录。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

## 获得帮助

在 [GitHub Issues](https://github.com/turinglambdaai/podlens/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
